# Configuración inicial de una cuenta AWS


> **🧭 En una mirada**
> - **Qué es:** una preparación segura y reproducible para una cuenta de laboratorio.
> - **Por qué importa:** reduce exposición de credenciales, sorpresas de coste y recursos olvidados.
> - **Cómo funciona:** MFA, acceso federado, presupuesto, región y etiquetas antes de desplegar.
> - **Para qué se usa:** ejecutar prácticas con AWS CLI sin access keys permanentes.

## Objetivo

Crear una cuenta de laboratorio con acceso seguro, control de costes y una forma reproducible de trabajar desde Windows y PowerShell.

## Checklist inicial

- [ ] MFA activado en root.
- [ ] No existen access keys para root.
- [ ] Presupuesto mensual configurado.
- [ ] Región principal elegida conscientemente.
- [ ] IAM Identity Center configurado.
- [ ] Perfil de AWS CLI creado.
- [ ] No hay credenciales en el repositorio.
- [ ] Los recursos se etiquetan con proyecto y entorno.

## Región y etiquetas

Elige una región próxima a tus usuarios y revisa la disponibilidad de cada servicio. Para los laboratorios utiliza una única región siempre que sea posible.

Etiquetas recomendadas:

```text
Project = paideia-aws-learning
Environment = lab
Owner = <tu-identificador>
ManagedBy = manual | terraform
```

## AWS CLI con SSO

```powershell
aws --version
aws configure sso --profile paideia-lab
aws sso login --profile paideia-lab
aws sts get-caller-identity --profile paideia-lab
```

No compartas la salida completa de identidad, tokens, cookies ni archivos de configuración que contengan secretos.

## Control de costes

- Crear un Budget con alertas de coste real y previsto.
- Revisar Cost Explorer después de cada laboratorio.
- Eliminar instancias, balanceadores, NAT Gateways, bases de datos y clusters cuando no se usen.
- No asumir que el Free Tier cubre todos los componentes.
- Revisar precios regionales antes de crear recursos.

## Convención de laboratorios

Cada laboratorio debe tener:

```text
objetivo → recursos → permisos → pasos → verificación → limpieza → reflexión
```

La limpieza no es opcional. Un laboratorio terminado debe dejar la cuenta en un estado conocido.
