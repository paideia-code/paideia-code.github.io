# Saga

Una Saga aborda el problema de mantener una operación de negocio coherente cuando sus pasos atraviesan varios servicios o almacenes que no comparten una transacción. Divide el flujo en transacciones locales y ejecuta acciones compensatorias cuando un paso posterior falla.
