# Event Sourcing

Event Sourcing aborda la necesidad de conservar el historial completo de cambios y reconstruir el estado actual sin sobrescribir los hechos anteriores. El estado se obtiene reproduciendo eventos, lo que exige gestionar evolución de esquemas, idempotencia y proyecciones.
