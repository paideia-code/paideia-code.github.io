# Specification

Aborda la duplicación de reglas de selección o validación, convirtiéndolas en objetos que pueden reutilizarse y combinarse.

## Relaciones

Se relaciona con la [separación de responsabilidades](/theory/diseno-arquitectura/principios/mantenibilidad/separacion-responsabilidades/) y el [encapsulamiento](/theory/diseno-arquitectura/principios/mantenibilidad/encapsulamiento/).

También tiene una aplicación tecnológica en Spring Data JPA para construir predicados y consultas dinámicas.
