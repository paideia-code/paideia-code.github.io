# Memento

## Intención
Guardar y restaurar el estado de un objeto sin exponer su representación interna.
## Problema
Una operación de undo necesita una instantánea, pero permitir que otro objeto manipule internals rompe invariantes.
## Solución
El originador crea un memento opaco y un cuidador lo almacena y devuelve cuando hace falta.
## Consecuencias
Permite undo y checkpoints, a cambio de memoria, coste de copia y decisiones sobre versiones o datos sensibles.
## Relaciones
Se combina con Command para operaciones reversibles y Prototype cuando copiar el estado es apropiado.
