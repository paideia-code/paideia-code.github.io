# Patrones GoF

Esta familia contiene los 23 patrones del libro de Erich Gamma, Richard Helm, Ralph Johnson y John Vlissides. Se organiza en Creacionales (1), Estructurales (2) y Comportamiento (3); GoF es una familia dentro de los patrones de mantenibilidad, no toda la sección.

## Relaciones

Los patrones ofrecen soluciones convencionales para contribuir al atributo de [mantenibilidad](/theory/diseno-arquitectura/atributos-calidad/mantenibilidad/) y aplicar principios como el [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/) y la [separación de responsabilidades](/theory/diseno-arquitectura/principios/mantenibilidad/separacion-responsabilidades/). Las tres familias se complementan, pero no deben confundirse con categorías de calidad.
