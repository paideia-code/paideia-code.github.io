# Cache-Aside

Cache-Aside aborda la latencia y la carga de consultas repetidas sin convertir la caché en la fuente principal de verdad. La aplicación consulta primero la caché; ante un fallo, lee el almacén persistente, devuelve el resultado y lo guarda en la caché.
