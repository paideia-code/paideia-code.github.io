# Sharding

Sharding aborda el límite de capacidad de un único nodo distribuyendo los datos por una clave de partición. Permite escalar almacenamiento y consultas horizontalmente, pero requiere elegir una distribución equilibrada y gestionar consultas que cruzan particiones.
