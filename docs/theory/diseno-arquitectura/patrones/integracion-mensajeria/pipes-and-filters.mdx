# Pipes and Filters

Patrón de *Enterprise Integration Patterns* que encadena filtros independientes mediante pipes para transformar y procesar mensajes por etapas.

Su desacoplamiento facilita escalar filtros de forma independiente y construir procesamiento de mensajes claro, reutilizable y observable.

## Relaciones

Se relaciona con el [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/), la [escalabilidad](/theory/diseno-arquitectura/atributos-calidad/escalabilidad/) y el procesamiento asíncrono de mensajes.
