# Patrones de integración y mensajería

Presenta patrones para transportar, enrutar, transformar y procesar mensajes entre componentes.

## Relaciones

Estos patrones aplican principios de [confiabilidad](/theory/diseno-arquitectura/principios/confiabilidad/) y [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/) para integrar componentes.

Incluye [Pipes and Filters](./pipes-and-filters/), un patrón de *Enterprise Integration Patterns* para desacoplar etapas de procesamiento de mensajes.
