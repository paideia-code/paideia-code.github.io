# Técnicas

Una técnica es una forma concreta de aplicar un principio en una decisión de diseño. No es todavía un patrón completo: describe una práctica o mecanismo, no una solución convencional con contexto, fuerzas y estructura completa.

En [Diseño y arquitectura](/theory/diseno-arquitectura/), las técnicas ocupan el nivel operativo entre los [principios](/theory/diseno-arquitectura/principios/) y los patrones: ayudan a implementar una decisión concreta, mientras que la arquitectura coordina muchas decisiones a escala del sistema.

Las familias se ordenan por el mismo criterio que los principios: primero la evolución del código, después la corrección y la respuesta ante fallos, la visibilidad operativa, la protección, la capacidad de crecimiento y, por último, la eficiencia.
