# Técnicas

Una técnica es una forma concreta de aplicar un principio en una decisión de diseño. No es todavía un patrón completo: describe una práctica o mecanismo, no una solución convencional con contexto, fuerzas y estructura completa.

Las [técnicas de mantenibilidad](/theory/diseno-arquitectura/tecnicas/mantenibilidad/) reúnen prácticas para reducir acoplamiento, aclarar responsabilidades y facilitar la evolución del código. También se agrupan técnicas de escalabilidad, resiliencia, confiabilidad, observabilidad, rendimiento y seguridad.
