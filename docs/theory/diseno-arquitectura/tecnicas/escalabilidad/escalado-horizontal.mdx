# Escalado horizontal

Añade instancias equivalentes y distribuye las solicitudes entre ellas, normalmente con un balanceador.

## Relaciones

Se relaciona con [Stateless](/theory/diseno-arquitectura/principios/escalabilidad/stateless/) y [Microservicios](/theory/diseno-arquitectura/arquitectura/arquitectura-sistema/microservicios/).
