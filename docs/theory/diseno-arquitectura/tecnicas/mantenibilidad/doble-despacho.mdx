# Doble despacho

El doble despacho es una técnica de polimorfismo que permite seleccionar una operación considerando los tipos dinámicos de dos objetos, en lugar de depender de una sola llamada virtual. Se estudiará cómo usarlo para mantener extensible la colaboración entre objetos.

## Relaciones

Se relaciona con [Visitor](/theory/diseno-arquitectura/patrones/mantenibilidad/gof/comportamiento/visitor/), que organiza esta técnica dentro de una solución convencional más completa.
