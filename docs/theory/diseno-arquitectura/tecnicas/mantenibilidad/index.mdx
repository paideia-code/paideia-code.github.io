# Técnicas de mantenibilidad

La [mantenibilidad](/theory/diseno-arquitectura/atributos-calidad/mantenibilidad/) es el atributo superior de esta familia. Estas técnicas aplican principios de mantenibilidad para mantener manejables las dependencias y responsabilidades del sistema.
