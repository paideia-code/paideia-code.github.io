# Técnicas de mantenibilidad

Reúne prácticas para aplicar principios de mantenibilidad y mantener manejables las dependencias y responsabilidades del sistema.

<SidebarCards />

## Relaciones

Estas técnicas aplican principios de [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/), [encapsulamiento](/theory/diseno-arquitectura/principios/mantenibilidad/encapsulamiento/) e [inversión de dependencias](/theory/diseno-arquitectura/principios/mantenibilidad/inversion-dependencias/). La composición sobre herencia se documenta como principio de mantenibilidad, no como técnica concreta.
