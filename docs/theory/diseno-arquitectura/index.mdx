# Diseño y arquitectura

Esta sección organiza el estudio desde los **[atributos de calidad](/theory/diseno-arquitectura/atributos-calidad)** hacia los **[principios](/theory/diseno-arquitectura/principios)**, las **[técnicas](/theory/diseno-arquitectura/tecnicas/)**, los **[patrones](/theory/diseno-arquitectura/patrones/)** y las decisiones de **[arquitectura](/theory/diseno-arquitectura/arquitectura/)**.

## Cómo se relacionan los conceptos

Los [atributos de calidad](/theory/diseno-arquitectura/atributos-calidad/) expresan las propiedades que queremos conseguir. Los [principios](/theory/diseno-arquitectura/principios/) son reglas de diseño; las [técnicas](/theory/diseno-arquitectura/tecnicas/) son formas concretas de aplicarlas; los [patrones](/theory/diseno-arquitectura/patrones/) ofrecen soluciones convencionales para problemas concretos; y la [arquitectura](/theory/diseno-arquitectura/arquitectura/) organiza esas decisiones a escala del sistema.

<ConceptCard title="Idea clave">
  Un patrón puede contribuir a varios atributos de calidad simultáneamente. Por ejemplo, [CQRS](/theory/diseno-arquitectura/patrones/escalabilidad/cqrs/) contribuye a la [escalabilidad](/theory/diseno-arquitectura/atributos-calidad/escalabilidad/) y el [rendimiento](/theory/diseno-arquitectura/atributos-calidad/rendimiento/) porque separa lecturas y escrituras para optimizar y escalar cada modelo de forma independiente.
</ConceptCard>

## Referencias

- [ISO/IEC 25010:2023 — modelo de calidad de producto](https://www.iso.org/standard/78176.html): marco para nombrar y relacionar atributos de calidad.
- [arc42 — documentación y vistas de arquitectura](https://arc42.org/documentation/): estructura práctica para comunicar decisiones arquitectónicas.
- [Design Patterns (GoF)](https://refactoring.guru/design-patterns): referencia accesible de patrones clásicos.
- [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/): catálogo de patrones para integración y mensajería.
- [CQRS, Martin Fowler](https://martinfowler.com/bliki/CQRS.html): explicación del patrón de separación de modelos de lectura y escritura.
- [Spring Data JPA Specifications](https://docs.spring.io/spring-data/jpa/reference/jpa/specifications.html): ejemplo concreto de composición de criterios de consulta.
