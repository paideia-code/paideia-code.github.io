# Atributos de calidad

Son propiedades observables o relevantes del sistema que ayudan a evaluar y comparar decisiones técnicas. No son funcionalidades aisladas: expresan criterios como mantenibilidad, seguridad o rendimiento que deben concretarse en escenarios y trade-offs.

Se usan al inicio para priorizar objetivos y durante el diseño para comprobar si principios, técnicas, patrones y arquitecturas contribuyen realmente a ellos. Un mismo elemento puede impactar en varios atributos.
