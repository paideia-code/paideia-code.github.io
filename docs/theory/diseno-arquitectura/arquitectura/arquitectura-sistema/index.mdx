# Arquitectura del sistema

Reúne estilos que definen cuántas unidades se despliegan, cómo se aíslan y qué autonomía tienen sus capacidades.

## Relaciones

Se relaciona con [Comunicación e integración](/theory/diseno-arquitectura/arquitectura/comunicacion-integracion/) y con los atributos de escalabilidad, resiliencia y confiabilidad.

También aplica principios como [stateless](/theory/diseno-arquitectura/principios/escalabilidad/stateless/) y [diseñar para el fallo](/theory/diseno-arquitectura/principios/resiliencia/disenar-para-el-fallo/), y se combina con patrones como [Circuit Breaker](/theory/diseno-arquitectura/patrones/resiliencia/circuit-breaker/) y [Saga](/theory/diseno-arquitectura/patrones/confiabilidad-consistencia/saga/).
