# Modularización y packages

Explica formas de dividir el código en módulos y paquetes. Contrasta la organización por capas técnicas con la organización por capacidades completas.

## Relaciones

La modularización busca mantenibilidad mediante [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/), [alta cohesión](/theory/diseno-arquitectura/principios/mantenibilidad/alta-cohesion/) y [encapsulamiento](/theory/diseno-arquitectura/principios/mantenibilidad/encapsulamiento/). Se relaciona con [monolito modular](/theory/diseno-arquitectura/arquitectura/arquitectura-sistema/monolito-modular/), [DDD](/theory/diseno-arquitectura/arquitectura/modelado-dominio/ddd/) y patrones como [Repository](/theory/diseno-arquitectura/patrones/mantenibilidad/repository/).
