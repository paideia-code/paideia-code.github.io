# Modelado del dominio

Introduce conceptos para expresar reglas, límites, lenguaje y colaboraciones del dominio. El modelo de dominio guía los límites de módulos y servicios, pero no prescribe una topología concreta.

## Relaciones

El modelado del dominio refuerza mantenibilidad y confiabilidad mediante [encapsulamiento](/theory/diseno-arquitectura/principios/mantenibilidad/encapsulamiento/) e [inversión de dependencias](/theory/diseno-arquitectura/principios/mantenibilidad/inversion-dependencias/). Se combina con [monolito modular](/theory/diseno-arquitectura/arquitectura/arquitectura-sistema/monolito-modular/), [Hexagonal](/theory/diseno-arquitectura/arquitectura/arquitectura-interna/hexagonal/) y patrones como [Saga](/theory/diseno-arquitectura/patrones/confiabilidad-consistencia/saga/) y [Transactional Outbox](/theory/diseno-arquitectura/patrones/confiabilidad-consistencia/transactional-outbox/).
