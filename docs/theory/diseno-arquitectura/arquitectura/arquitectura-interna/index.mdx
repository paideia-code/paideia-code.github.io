# Arquitectura interna

Presenta estilos para dirigir dependencias y proteger las reglas de negocio frente a detalles externos.

## Relaciones

Estos estilos contribuyen principalmente a la mantenibilidad y la seguridad. Aplican [bajo acoplamiento](/theory/diseno-arquitectura/principios/mantenibilidad/bajo-acoplamiento/), [alta cohesión](/theory/diseno-arquitectura/principios/mantenibilidad/alta-cohesion/) e [inversión de dependencias](/theory/diseno-arquitectura/principios/mantenibilidad/inversion-dependencias/), y se combinan con patrones como [Repository](/theory/diseno-arquitectura/patrones/mantenibilidad/repository/) y [Service Layer](/theory/diseno-arquitectura/patrones/mantenibilidad/service-layer/).
