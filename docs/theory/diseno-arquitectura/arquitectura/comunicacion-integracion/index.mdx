# Comunicación e integración

Reúne estilos de comunicación e integración entre componentes. Ordena primero la coordinación directa y después los mecanismos asíncronos basados en eventos y mensajes.

## Relaciones

Estos estilos afectan confiabilidad, resiliencia y observabilidad. Se apoyan en [idempotencia](/theory/diseno-arquitectura/principios/confiabilidad/idempotencia/), [diseñar para el fallo](/theory/diseno-arquitectura/principios/resiliencia/disenar-para-el-fallo/) y [correlación de operaciones](/theory/diseno-arquitectura/principios/observabilidad/correlacion-de-operaciones/), y se concretan con [patrones de integración y mensajería](/theory/diseno-arquitectura/patrones/integracion-mensajeria/), [Retry](/theory/diseno-arquitectura/patrones/resiliencia/retry/) y [Correlation Identifier](/theory/diseno-arquitectura/patrones/observabilidad/correlation-identifier/).
