# Event-driven architecture (EDA)

Un estilo en el que los componentes publican eventos y reaccionan a ellos sin depender de una llamada directa entre productor y consumidor.

## Relaciones

Se relaciona con [Pub-sub](./pub-sub/), [Message queues](./message-queues/) y los [patrones de integración y mensajería](/theory/diseno-arquitectura/patrones/integracion-mensajeria/).
