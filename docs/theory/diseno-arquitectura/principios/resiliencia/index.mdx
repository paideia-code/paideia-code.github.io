# Principios de resiliencia

Esta categoría conserva únicamente principios de resiliencia. Las formas concretas de contener fallos, limitar esperas y regular carga están en [Técnicas de resiliencia](/theory/diseno-arquitectura/tecnicas/resiliencia/).
El contenido de esta categoría se ampliará cuando se incorporen principios concretos.
