# Principios de resiliencia

La [resiliencia](/theory/diseno-arquitectura/atributos-calidad/resiliencia/) es el atributo superior de esta familia. Sus principios orientan la respuesta del sistema ante fallos, degradación y recuperación.

Esta categoría conserva únicamente principios de resiliencia. Las formas concretas de contener fallos, limitar esperas y regular carga están en las [técnicas de resiliencia](/theory/diseno-arquitectura/tecnicas/resiliencia/).
