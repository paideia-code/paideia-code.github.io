# Principios

Los principios son reglas e ideas de diseño que orientan decisiones y pueden contribuir a varios atributos de calidad; aquí se organizan por el atributo donde tienen su aplicación principal.

El orden común de las categorías es: mantenibilidad, confiabilidad, resiliencia, observabilidad, seguridad, escalabilidad y rendimiento.
