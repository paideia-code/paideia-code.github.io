# Principios de mantenibilidad

La [mantenibilidad](/theory/diseno-arquitectura/atributos-calidad/mantenibilidad/) es el atributo superior de esta familia. Estos principios orientan el diseño hacia cambios locales, dependencias manejables y responsabilidades claras.

## Relaciones

El bajo acoplamiento, la alta cohesión, el encapsulamiento, la separación de responsabilidades y la simplicidad aportan la base de modularidad sobre la que se aplican la inversión de dependencias, SOLID y [CQS](/theory/diseno-arquitectura/principios/mantenibilidad/cqs/). Las decisiones concretas pueden continuar en las [técnicas de mantenibilidad](/theory/diseno-arquitectura/tecnicas/mantenibilidad/).
