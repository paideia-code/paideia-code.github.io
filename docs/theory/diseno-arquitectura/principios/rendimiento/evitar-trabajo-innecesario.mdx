# Evitar trabajo innecesario

Reduce pasos redundantes y mueve el trabajo fuera del camino de una petición cuando no sea necesario hacerlo de inmediato.

## Relaciones

Se relaciona con el atributo de [rendimiento](/theory/diseno-arquitectura/atributos-calidad/rendimiento/) y con el patrón [Cache](/theory/diseno-arquitectura/patrones/escalabilidad/cache/), una aplicación concreta de este principio.

Una cache, un batch o una paginación son aplicaciones concretas de este principio, no el principio en sí mismo.
