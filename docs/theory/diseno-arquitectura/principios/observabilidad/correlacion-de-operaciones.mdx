# Correlación de operaciones

Propaga identificadores y contexto suficiente para reconstruir una operación distribuida de principio a fin.

## Relaciones

Se relaciona con el atributo de [observabilidad](/theory/diseno-arquitectura/atributos-calidad/observabilidad/), la técnica de [correlación](/theory/diseno-arquitectura/tecnicas/observabilidad/correlacion/) y el patrón [Correlation Identifier](/theory/diseno-arquitectura/patrones/observabilidad/correlation-identifier/).
