# Principios de observabilidad

La [observabilidad](/theory/diseno-arquitectura/atributos-calidad/observabilidad/) es el atributo superior de esta familia. Estos principios incorporan la capacidad de entender el estado y comportamiento del sistema a las decisiones de diseño, en lugar de añadirla únicamente al final.
