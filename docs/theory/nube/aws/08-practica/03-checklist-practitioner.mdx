# Checklist AWS Certified Cloud Practitioner


> **🧭 En una mirada**
> - **Qué es:** una lista de comprobación de conocimientos base de AWS.
> - **Por qué importa:** ayuda a detectar huecos antes de presentar el examen.
> - **Cómo funciona:** repasa cloud, seguridad, servicios, costes y soporte con preguntas.
> - **Para qué se usa:** preparar CLF-C02 y decidir qué temas requieren práctica adicional.

## Conceptos cloud

- [ ] IaaS, PaaS, SaaS y serverless.
- [ ] Regiones, AZs y edge locations.
- [ ] Elasticidad, escalabilidad, alta disponibilidad y resiliencia.
- [ ] Modelo de responsabilidad compartida.

## Seguridad

- [ ] IAM, usuarios, grupos, roles y policies.
- [ ] MFA y credenciales temporales.
- [ ] IAM Identity Center.
- [ ] KMS, Secrets Manager y Parameter Store.
- [ ] CloudTrail, GuardDuty, Config y Security Hub.

## Servicios principales

- [ ] EC2, Auto Scaling y ELB.
- [ ] Lambda y API Gateway.
- [ ] S3, EBS y EFS.
- [ ] RDS, Aurora, DynamoDB y ElastiCache.
- [ ] VPC, subredes, route tables, gateways y Security Groups.
- [ ] SQS, SNS y EventBridge.
- [ ] ECS, Fargate, ECR y EKS.
- [ ] CloudWatch y CloudFront.

## Costes y soporte

- [ ] Budgets y Cost Explorer.
- [ ] AWS Pricing Calculator.
- [ ] On-Demand, Reserved, Savings Plans y Spot.
- [ ] Transferencia de datos.
- [ ] Cuotas y planes de soporte.

## Preparación

No memorices únicamente definiciones. Practica preguntas de elección arquitectónica: qué servicio reduce operación, cuál ofrece una capacidad concreta, qué control pertenece al cliente y qué opción minimiza riesgo o coste.
