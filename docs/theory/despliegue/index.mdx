# Despliegue

El despliegue conecta el diseño de un sistema con su ejecución real. Esta sección es provider-neutral y se organiza alrededor de infraestructura, redes, runtime, entrega continua y operación.

[Cloud](/theory/nube/) es una de las formas de desplegar y operar sistemas. Los proveedores concretos se documentan aparte, dentro de [Tecnologías](/theory/tecnologias/); por ejemplo, la [guía de AWS](/theory/nube/aws/), que conserva su URL histórica aunque ahora esté organizada bajo Proveedores cloud.
