# Cloud

Cloud aporta capacidades de infraestructura y servicios para desplegar y operar sistemas; no sustituye las decisiones de diseño y arquitectura. Esta subsección presenta conceptos comunes a distintos proveedores.


Los proveedores concretos se enlazan desde [Tecnologías > Proveedores cloud](/theory/tecnologias/plataformas/). La [guía de AWS](/theory/nube/aws/) conserva su URL pública y concentra el recorrido específico de esa plataforma.
