# Tecnologías

Esta sección se organiza en lenguajes, frameworks, librerías, bases de datos, proveedores cloud y herramientas para construir, probar y operar sistemas.

Las tecnologías son medios para implementar decisiones; no deben confundirse con los atributos que se buscan ni con la arquitectura que organiza el sistema. La elección tecnológica se contrasta con el diseño, las restricciones operativas y el contexto de despliegue.

Los proveedores cloud pertenecen aquí porque son tecnologías concretas. La [guía de AWS](/theory/nube/aws/) se mantiene en su URL pública, pero se navega desde [Proveedores cloud](/theory/tecnologias/plataformas/) para no confundir un proveedor con el concepto general de Cloud.
