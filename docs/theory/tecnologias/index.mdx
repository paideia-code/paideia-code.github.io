# Tecnologías

Lenguajes, frameworks y ecosistemas. Esta sección está preparada para incorporar Go y futuros contenidos tecnológicos cuando estén disponibles.

Las tecnologías son medios para implementar decisiones; no deben confundirse con los atributos que se buscan ni con la arquitectura que organiza el sistema. La elección tecnológica se contrasta con el diseño, las restricciones operativas y el contexto de despliegue.
