# EBS, EFS y selección de almacenamiento


> **🧭 En una mirada**
> - **Qué es:** comparación entre almacenamiento de bloques y sistema de archivos compartido.
> - **Por qué importa:** el patrón de acceso determina rendimiento, disponibilidad y coste.
> - **Cómo funciona:** EBS se adjunta a EC2; EFS expone un filesystem regional compartido.
> - **Para qué se usa:** elegir persistencia para máquinas, aplicaciones distribuidas y archivos compartidos.

| Servicio | Tipo | Uso |
|---|---|---|
| EBS | Bloques | Disco de una instancia EC2 |
| EFS | Archivos compartidos | Varios workloads montando el mismo filesystem |
| S3 | Objetos | Archivos, backups, datos estáticos y data lakes |

## Decisión rápida

- Necesitas un disco para un servidor: EBS.
- Necesitas un filesystem compartido entre instancias: EFS.
- Necesitas almacenar objetos mediante API HTTP: S3.

S3 no ofrece la semántica de un filesystem POSIX. EBS no se comparte libremente entre instancias y está asociado a una AZ en la mayoría de configuraciones.
