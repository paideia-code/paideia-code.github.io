# Mapa de servicios AWS


> **🧭 En una mirada**
> - **Qué es:** un mapa por capacidades de los servicios más relevantes de esta ruta.
> - **Por qué importa:** permite empezar por el problema y no por el nombre del servicio.
> - **Cómo funciona:** agrupa identidad, red, cómputo, datos, integración y operación.
> - **Para qué se usa:** orientar elecciones iniciales y detectar servicios alternativos.

## Fundamentos y gobierno

| Área | Servicios | Pregunta que responden |
|---|---|---|
| Identidad | IAM, IAM Identity Center, STS | ¿Quién puede acceder? |
| Gobierno | Organizations, Control Tower | ¿Cómo gestiono varias cuentas? |
| Costes | Billing, Budgets, Cost Explorer | ¿Cuánto cuesta? |
| Auditoría | CloudTrail, Config | ¿Qué ocurrió y qué cambió? |

## Red y entrega

| Servicio | Uso principal |
|---|---|
| VPC | Red aislada virtual |
| Route 53 | DNS y health checks |
| Elastic Load Balancing | Distribuir tráfico |
| CloudFront | CDN y entrega global |
| API Gateway | APIs HTTP, REST y WebSocket |

## Cómputo

| Servicio | Uso principal |
|---|---|
| EC2 | Máquinas virtuales con control del sistema operativo |
| Lambda | Funciones bajo demanda |
| ECS | Contenedores gestionados |
| Fargate | Ejecución de contenedores sin gestionar servidores |
| EKS | Kubernetes gestionado |

## Almacenamiento y datos

| Servicio | Uso principal |
|---|---|
| S3 | Objetos y archivos |
| EBS | Discos para EC2 |
| EFS | Sistema de archivos compartido |
| RDS | Bases de datos relacionales gestionadas |
| DynamoDB | NoSQL gestionada de baja latencia |
| ElastiCache | Caché en memoria |

## Integración

| Servicio | Uso principal |
|---|---|
| SQS | Cola y desacoplamiento |
| SNS | Publicación y notificación fan-out |
| EventBridge | Enrutamiento de eventos |
| Step Functions | Orquestación de workflows |
| MSK | Kafka gestionado |

## Operación

| Servicio | Uso principal |
|---|---|
| CloudWatch | Métricas, logs, alarmas y dashboards |
| X-Ray | Trazas distribuidas |
| CloudTrail | Registro de llamadas a la API |
| Systems Manager | Gestión operativa |
| Secrets Manager | Secretos con rotación |
| KMS | Claves de cifrado |

## Pregunta de selección

Antes de elegir un servicio, responde:

1. ¿Qué problema concreto resuelve?
2. ¿Necesito control del servidor o solo ejecutar código?
3. ¿La carga es síncrona, asíncrona o orientada a eventos?
4. ¿Qué disponibilidad y latencia necesito?
5. ¿Qué permisos y datos maneja?
6. ¿Cómo se factura y cómo lo apagaré?
