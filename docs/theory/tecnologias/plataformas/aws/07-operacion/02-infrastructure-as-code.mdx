# Infrastructure as Code


> **🧭 En una mirada**
> - **Qué es:** describir infraestructura en código versionado y reproducible.
> - **Por qué importa:** reduce cambios manuales, deriva de configuración y errores de repetición.
> - **Cómo funciona:** una herramienta calcula un plan, aplica cambios y mantiene estado controlado.
> - **Para qué se usa:** crear, revisar, recrear y retirar entornos de forma consistente.

## Objetivo

Definir infraestructura como código versionado, revisable, reproducible y destruible.

## Terraform

Conceptos:

- Providers.
- Resources.
- Variables y outputs.
- Modules.
- State.
- Plan y apply.

Flujo recomendado:

```text
terraform fmt
terraform validate
terraform plan
terraform apply
terraform destroy
```

Nunca aplicar infraestructura desde archivos con secretos ni almacenar el state sin protegerlo. En equipos, usar backend remoto con locking y control de acceso.

## AWS CDK y CloudFormation

CDK permite definir infraestructura usando lenguajes de programación y genera CloudFormation. Es una alternativa adecuada si quieres reutilizar abstracciones de TypeScript, Python, Java o C#.

## 🧩 Terraform frente a CDK

| Criterio | Terraform | CDK |
|---|---|---|
| Modelo | HCL y providers | Lenguaje de programación + CloudFormation |
| Multi-cloud | Habitual | Principalmente AWS |
| Abstracciones | Modules | Constructs |
| Estado | State explícito | CloudFormation administra el estado de despliegue |
| Para Paideia | Buena opción si se busca IaC portable | Buena opción si se prioriza Java/TypeScript |

La herramienta importa menos que revisar planes, proteger el estado, controlar permisos y automatizar el ciclo de vida.

## Paideia

Crear módulos separados para red, seguridad, datos, ECR, ECS y observabilidad. No crear un módulo gigantesco que mezcle todo sin fronteras claras.

## ⚠️ Errores frecuentes

- Ejecutar `apply` sin revisar el plan.
- Versionar el state o secretos.
- Crear recursos manualmente que luego no existen en IaC.
- Compartir un state sin locking.
- Usar el mismo entorno y permisos para laboratorio y producción.
