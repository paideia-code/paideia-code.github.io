# Glosario AWS esencial


> **🧭 En una mirada**
> - **Qué es:** definiciones breves de términos recurrentes en la ruta.
> - **Por qué importa:** un vocabulario común evita confundir servicios, límites y responsabilidades.
> - **Cómo funciona:** cada entrada resume el concepto y apunta al documento donde se profundiza.
> - **Para qué se usa:** repasar rápidamente y preparar conversaciones técnicas o exámenes.

| Término | Significado |
|---|---|
| ARN | Identificador único de un recurso AWS |
| AZ | Availability Zone dentro de una región |
| CIDR | Notación para rangos de direcciones IP |
| CloudTrail | Registro de llamadas a APIs AWS |
| IAM | Gestión de identidades y acceso |
| IaC | Infraestructura definida como código |
| Least privilege | Otorgar solo permisos necesarios |
| Multi-AZ | Distribución entre zonas de disponibilidad |
| RPO | Pérdida máxima de datos aceptable |
| RTO | Tiempo máximo de recuperación aceptable |
| SCP | Service Control Policy en Organizations |
| SG | Security Group, firewall stateful |
| STS | Servicio de credenciales temporales |
| VPC | Red virtual aislada |
| Workload | Aplicación o proceso que se ejecuta en AWS |
