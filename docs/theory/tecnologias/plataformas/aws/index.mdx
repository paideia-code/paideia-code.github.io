## Programa de estudio {#programa}

Cada lección desarrolla un tema mediante explicaciones, ejemplos y preguntas.
El recorrido avanza desde las bases hacia redes, cómputo, datos, integración,
seguridad, observabilidad e infraestructura. El Glosario de Bases sirve como
referencia durante todo el recorrido.

<CourseProgram chapters={awsBlocks} label="Programa de AWS" />

Las prácticas se plantean como laboratorios y POC acotadas, para comprobar
decisiones concretas sin convertir el recorrido en un único proyecto obligatorio.

## Fuentes para profundizar

- [Documentación oficial de AWS](https://docs.aws.amazon.com/): comportamiento y configuración de los servicios.
- [AWS Well-Architected](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html): criterios para examinar decisiones de arquitectura.
